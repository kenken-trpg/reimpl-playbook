# How to add a rule / feature

具体的な手順書。各レシピは「テストを足す」で終わる——
テストのない規則変更はマージしない、という方針を手順に埋め込むため。
既存のテストをコピーして始めるのが最短。

---

## 新しい [修正子 / 効果タグ] を足す

1. **解析** — 大抵やることはない。[パーサ] が既に汎用の形に落としている。
2. **ディスパッチ** — `[handlers/*.py]` にハンドラを足す：
   ```python
   @handles("[tag]")
   def _tag(tag, node, fields, effects, source) -> None:
       effects["[key]"] += _as_int(node.get("value"))
   ```
   登録はこれだけ。別の一覧表を更新する必要はない（[06](../../docs/06-coverage.md)）。
   - 認識した上で無視すべきものは `SILENT` に理由つきで足す。
3. **消費** — 最終値を組み立てる場所で `effects["[key]"]` を読む。
4. **表に出す** — [表示側の型] に足して描画する。
5. **テスト** — 実データからその修正子を持つ項目を選び、状態を組んで出力を検証する。

## 新しい項目フィールドを足す

3. 型に足す（[04](../../docs/04-boundary-types.md) — 生成なら生成し直す）
4. テスト
