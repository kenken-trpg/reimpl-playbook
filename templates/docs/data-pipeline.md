# Data pipeline

## なぜデータが git に入っていないか

[ライセンスと再現性。docs/02-upstream-pin.md を参照]

```
tools/pin/fetch_upstream.py
  └─ 固定した FILES を raw.githubusercontent から、ピンした ref で
     vendor/upstream/ へ        (gitignored)
```

`make data` がこれを実行する。CI は `vendor/` を
**取得スクリプトのハッシュ**で鍵付けしてキャッシュする
（ref だけを鍵にすると FILES の追加でキャッシュが外れない）。

## 解析

- `load_<kind>()` は 1 ファイル 1 関数。**全域にすること**：
  ファイルが無ければ `[]` / `{}` を返し、例外を投げない
  （任意ファイルがあり、ローダが落ちると全体が死ぬ）。
- `catalog()` が全部を呼んで 1 つの構造にし、相互参照を解決する。
  プロセスごとに 1 回だけ（キャッシュ）。
